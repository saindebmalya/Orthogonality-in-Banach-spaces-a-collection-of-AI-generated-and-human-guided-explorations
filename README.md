# Orthogonality in Banach spaces: a collection of AI-generated and human-guided explorations

> **Warning: the results in this repository may contain errors.**
> They were produced by an AI model and have NOT necessarily been verified by humans yet. Do not rely on any result here without checking its proof yourself. Each manuscript states its verification status on its first page.

This repository collects results on orthogonality in Banach spaces that were produced by an AI model under the guidance of Dr. Debmalya Sain and his collaborators. The results are not meant for publication, but for the advancement of knowledge.

## Errors: please help us find them

Finding errors is the most valuable contribution a reader can make here. Please open an issue in this repository if you find:

- **a false statement**, or a counterexample to a stated result;
- **a gap in a proof**, or a step that does not follow;
- **a missing acknowledgement**: an earlier source for a result, or a result used without citation;
- **a wrong reference**: incorrect authors, titles, volumes or pages.

Please name the manuscript and the numbered statement (for example, "Lemma 3.3"), and explain the problem as precisely as you can.

## How errors are handled

- Every reported error is checked.
- A confirmed error is corrected in the manuscript, and the correction is recorded in an errata list at the end of that manuscript, with the date and the name of the person who found it (unless they prefer to remain anonymous).
- If an error cannot be repaired, the affected result is marked as withdrawn rather than silently removed.
- Errors are never hidden: the history of every file remains visible in this repository.
